# Security Policy

Nootropics Map is a public evidence-navigation project. It should never receive sensitive user, medical, credential, customer, employer, or infrastructure data.

## Do not commit

- API keys, tokens, credentials, cookies, or session material;
- `.env` files;
- private keys or certificates;
- personal medical information;
- confidential client or employer material;
- private infrastructure identifiers;
- third-party copyrighted source files without rights to redistribute them.

## Data model

Only public source metadata and bounded evidence assessments belong in `data/`. Source text is summarized rather than mirrored.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when enabled for this repository. Please do not publish exploit details in a public issue before a fix is available.
